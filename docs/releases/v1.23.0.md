# WuPage v1.23.0

## 改进与修复

- 修复 TI 在线文档阅读器等页面无法翻译的问题，保留链接交互、显示模式切换和原文恢复。[#103](https://github.com/mr-wuliu/wupage/pull/103)
- 改善原生弹窗、浮层和嵌入文档的翻译，支持打开弹窗或组件内容显示后继续翻译。
- 改善组件插槽、页面滚动容器和裁剪样式的识别，修复部分可见正文漏译以及隐藏文字被误翻译的问题。

## 更新说明

更新后请刷新已打开的网页。解压安装需要手动替换安装包并重新加载扩展。Edge 和 Firefox 商店版通过各自商店更新。GitHub Release 中的 Firefox ZIP 未经 Mozilla 签名，仅供临时测试。
