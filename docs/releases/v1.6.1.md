# WuPage v1.6.1

## 紧急修复

- 修复 7-Zip 等使用表格布局的页面中，多个列表项被合并翻译、原位置变空或译文移到页面末尾的问题。列表项现在分别保留译文位置，支持三种显示模式及完整恢复原文。
- 修复设置页、弹窗、网页和 PDF 工作区同时修改配置时，较早读取的配置可能覆盖新设置或服务凭据的问题。
- 修复已有视频存在时，后来挂载到网页组件中的视频无法自动发现的问题；切回页面时及时刷新播放器。

## 优化

- 新增粉色、蓝色和黑白界面配色。
- 整理翻译服务和正文扫描实现，补充列表布局、配置并发保存及视频发现的回归验证。

更新后，请重新加载扩展，并刷新已打开的网页。
