# WuPage v1.7.0

## 新功能

- **设置备份与恢复**：可将设置导出为 TOML 文件并导入恢复，包含翻译服务、请求模板、网站规则和字幕布局等配置。默认不包含 API 密钥，需要完整迁移凭据时可在导出确认窗口勾选「包含密钥」。备份不包含翻译缓存及模型。
- **按网站调整字幕布局**：可在播放器内调整字幕位置、宽度和字号，预览后点击完成保存。布局按网站分别记忆，调整时无需重启翻译。
- **独立 Chromium 签名包**：新增使用固定扩展 ID 的 CRX 安装包，成功安装后可通过项目网站检查正式版更新。能否安装和自动更新取决于浏览器及设备策略；解压加载的 ZIP 仍需手动更新。

## 优化与修复

- 改善网页译文对原文结构的保留，维持句内格式、网页组件和交互控件的节点关系，支持切换显示模式及恢复原文。
- 修复 Discord 消息翻译适配，以及插槽式自定义控件的文字位置与显示问题。
- 改善 PDF 翻译的中断恢复、局部重试和阅读区域优先处理，保留已完成的部分译文，并修复学术文档的排版问题。
- 完全重置设置前新增确认，统一保存、重置操作的反馈，并限制局部恢复默认值的影响范围。
- 完善无密钥备份的凭据处理，保留其他配置内容。导入无密钥备份会清空原有凭据，之后需要重新配置翻译服务。

## 更新说明

- 首次从旧版解压安装切换到固定扩展 ID 时，请先导出设置，安装新版后再导入；需要迁移 API 凭据时，导出时勾选「包含密钥」。新旧扩展同时存在时，只启用其中一个。
- Windows、macOS 上的普通 Chrome 请继续使用 ZIP 解压加载；Edge 和 Firefox 商店版通过各自商店更新。GitHub Release 中的 Firefox ZIP 未经 Mozilla 签名，仅供临时测试。
- 无密钥备份会清理已识别的认证信息，但自定义请求正文中的手写密钥仍需在分享前人工检查。

更新后，请重新加载扩展，并刷新已打开的网页。
