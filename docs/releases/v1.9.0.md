# WuPage v1.9.0

## 新功能

- 新增触屏段落点选：点击「点选段落」后轻点正文，完成一次翻译后自动退出；再次点选同一段可恢复原文。滚动、链接及编辑区保持原有操作。
- 触屏悬浮球支持轻点翻译全文、长按打开菜单和拖动调整位置，并提供首次操作提示。窄屏菜单显示在页面底部，扩展弹窗优先显示全文翻译，其他工具可通过「更多功能」展开。
- 触屏划词使用系统选区，并在页面底部显示「查词」或「翻译所选」入口；改善短视口下的翻译卡片布局。图片翻译按钮在触屏设备上保持可见，便于选中图片后操作。

## 改进与修复

- 悬浮菜单和扩展弹窗显示本地语言模型的安装、下载及错误状态，并提供「管理模型」入口。
- 修复邮件列表翻译后标题、预览和时间挤压或换行的问题，改善窄窗口和长译文的显示。
- 改善嵌入文档的连接恢复，避免隐藏辅助文档失联时干扰正常网页翻译，并保留可见正文的真实错误提示。

## 更新说明

更新后，请重新加载扩展，并刷新已打开的网页。触屏功能需要浏览器支持扩展；系统选区、软键盘及浏览器工具栏的表现仍取决于具体设备和浏览器。Edge 和 Firefox 商店版通过各自商店更新；GitHub Release 中的 Firefox ZIP 未经 Mozilla 签名，仅供临时测试。
