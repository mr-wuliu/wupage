# WuPage v1.21.0

## 新功能

- 图片翻译支持自定义 OCR 服务，可配置接口、认证、请求内容和识别结果映射，并在设置中预览识别结果。[#93](https://github.com/mr-wuliu/wupage/pull/93)
- 网站规则支持指定强制翻译区域，便于处理默认过滤的内容。[#83](https://github.com/mr-wuliu/wupage/pull/83)
- 快捷键支持单键、符号键、数字小键盘及 Ctrl、Alt、Shift、Win / Command 组合。录入器支持绑定 Esc、Tab、Backspace 和 Delete，并提示按键冲突；浏览器和系统占用的按键仍可能无法触发。
- 外观设置新增段落高亮开关，可隐藏段落边框与底色，保留段落翻译操作。[#89](https://github.com/mr-wuliu/wupage/pull/89)

## 改进与修复

- 改善 PDF 的表格单元格、多栏正文、插图绕排、公式与引用保留；导出前检查文字溢出、重叠和字体缺字，无法完整排版时提示并阻止不完整导出。[#78](https://github.com/mr-wuliu/wupage/pull/78) · [#91](https://github.com/mr-wuliu/wupage/pull/91)
- 统一网页正文的段落识别，保留显式换行、行内格式及原有交互，改善动态页面和划词翻译的稳定性。[#79](https://github.com/mr-wuliu/wupage/pull/79) · [#85](https://github.com/mr-wuliu/wupage/pull/85) · [#88](https://github.com/mr-wuliu/wupage/pull/88)
- Google 免费翻译优先使用网页 HTML 接口，必要时切换备用协议，并改善单词查词的回退处理。[#97](https://github.com/mr-wuliu/wupage/pull/97)
- 支持翻译 Twitch 聊天消息正文，保留昵称及相邻消息的独立结构。[#94](https://github.com/mr-wuliu/wupage/pull/94)
- 将文本翻译和 OCR 服务设置分别展示，改善弹窗布局、图片翻译控件及窄屏菜单；弹窗新增项目支持入口。[#95](https://github.com/mr-wuliu/wupage/pull/95) · [#96](https://github.com/mr-wuliu/wupage/pull/96)
- 修复 GitHub 仓库文件标签页和 NVIDIA 驱动搜索与扩展交互时的问题，调整窄屏字幕默认外观。[#82](https://github.com/mr-wuliu/wupage/pull/82) · [#89](https://github.com/mr-wuliu/wupage/pull/89)
