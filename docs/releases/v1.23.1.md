# WuPage v1.23.1

## 改进与修复

- 默认设置备份省略密钥和自定义服务请求配置。需要迁移 API 凭据、自定义接口或 OCR 配置时，请勾选「包含密钥」并妥善保管备份。
- 清除或停用翻译缓存后，正在处理的文本和图片任务不会重新写入缓存。
- 「非目标语言」自动翻译可区分简体和繁体中文。网站及翻译区域规则支持匹配路径中含 `://` 的地址。翻译区域规则也支持域名和路径通配符及正则表达式。
- 可搜索 PDF 导出保留原稿的 HTTP 和 HTTPS 链接及其点击位置，改善图表标签的保留效果，并减少长文档翻译调度和导出时的开销。
- 改善网页组件中的划词和段落选区恢复，修复视频字幕浮层遮挡其他网页控件的问题。
- 图片翻译的右键菜单和悬浮入口可分别设置。改善 X 图片菜单交互及受限制页面的入口提示。

## 更新说明

更新后请刷新已打开的网页。解压安装需要手动替换安装包并重新加载扩展。GitHub Release 中的 Firefox ZIP 供临时测试使用。
