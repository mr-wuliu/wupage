# WuPage v1.10.0

## 新功能

- 「设置 → 通用 → 界面语言」支持简体中文、English 和跟随浏览器。点击「保存」后设置页会自动切换。已打开的网页和 PDF 刷新后生效。译文语言仍在「目标语言」中设置。
- 在支持的输入框和编辑器中，可以选中文字进行翻译，并用译文替换选中的内容。替换前会检查原文是否仍与翻译时一致。[#59](https://github.com/mr-wuliu/wupage/issues/59)
- 视频长字幕会随播放进度分页，每种语言每屏最多两行。字幕设置支持交换原文和译文的上下位置，也能分别调整两者的字号、字体和字重。[#70](https://github.com/mr-wuliu/wupage/issues/70) · [#71](https://github.com/mr-wuliu/wupage/issues/71)

## 改进与修复

- 修复部分带格式的段落需要第二次 Ctrl 点击才显示译文的问题。翻译等待期间移开鼠标，首次点击的译文也能正常显示。[#69](https://github.com/mr-wuliu/wupage/issues/69)
- 改善字幕分句和播放进度同步，关闭字幕翻译后恢复原生字幕。
- 改善豆包翻译的源语言自动检测。Google 网页翻译遇到连接错误时会尝试备用接口。
- PDF 完整导出字体支持从文件安装。可以在网络正常的设备下载字体，再复制到本机安装。

## 更新说明

更新后请重新加载扩展，并刷新已打开的网页。Edge 和 Firefox 商店版通过各自商店更新。GitHub Release 中的 Firefox ZIP 未经 Mozilla 签名，仅供临时测试。
