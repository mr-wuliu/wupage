# WuPage v1.7.1

## 修复

- 修复网页停留一段时间后，点击翻译无效并提示「暂无可翻译内容」的问题。扩展后台重新启动后，会重新识别当前页面和嵌入页面，恢复翻译任务的下发。
- 修复后台重新启动后，嵌入页面的停止翻译、恢复已有译文和翻译数量统计。
- 恢复页面状态时校验当前文档身份，避免使用导航前的旧状态；页面连接失败时显示明确错误。
- 修正 Edge 商店安装包，移除商店不接受的固定公钥和自托管更新地址字段。

## 更新说明

更新后，请重新加载扩展，并刷新已打开的网页。Edge 和 Firefox 商店版通过各自商店更新；GitHub Release 中的 Firefox ZIP 未经 Mozilla 签名，仅供临时测试。
