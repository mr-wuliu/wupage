# WuPage v1.22.0

## 改进与修复

- 修复 Outlook 网页邮箱正文无法翻译的问题，支持整页、段落翻译和切换邮件后继续翻译，保留编辑框保护及用户排除规则。[#100](https://github.com/mr-wuliu/wupage/pull/100)
- 修复 PDF 斜向水印连同周围原文一起覆盖译文的问题，预览及导出时保留水印和旋转文字，避免遮挡正文译文。[#101](https://github.com/mr-wuliu/wupage/pull/101)
- 修复 random.org 等网页的段首、段尾注释导致超链接失效的问题，保留链接地址、点击行为、显示模式切换和原文恢复。[#102](https://github.com/mr-wuliu/wupage/pull/102)

## 更新说明

更新后请刷新已打开的网页。解压安装需要手动替换安装包并重新加载扩展。Edge 和 Firefox 商店版通过各自商店更新。GitHub Release 中的 Firefox ZIP 未经 Mozilla 签名，仅供临时测试。
