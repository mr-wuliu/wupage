## 新增图片覆盖翻译

- 使用本地 PaddleOCR 识别图片中的文字与位置，再由当前翻译服务翻译；无需视觉模型，图片像素不发送给翻译服务。
- 鼠标悬浮图片时显示「译」按钮，也可右键选择「使用 WuPage 翻译图片」。支持切换原图与译文，兼容 X 帖子及大图查看器。
- 通过扳手安装约 20.5 MB 的 OCR 模型，安装后可用垃圾桶删除；说明、进度与模型状态收进「？」提示。
- 跳过纯数字、百分比等无需翻译的内容，按文字区域覆盖译文，并从原图采样颜色。

## 网页翻译改进

- 修复快速滚动后返回时部分段落漏译，以及 Gmail 正文、内部滚动区域和动态内容的识别问题。
- 改进翻译上下文与提示词，保留术语、语气、数字、链接和占位符；加强空译文、异常批次及过期缓存处理。
- 增加 DeepSeek 服务预设，以及译文替换、原色对照、双色对照三种显示模式。
- 修复 X 图片覆盖层被隐藏的问题，调整 OCR 日志级别并优化画布像素读取。

## 安装与升级

下载 `wupage-1.1.0-edge.zip` 并解压，在 Edge 或 Chrome 扩展管理页加载解压目录。已有用户替换扩展文件后重新加载扩展，并刷新已打开的网页。

图片翻译默认关闭。首次使用需在图片翻译旁点击扳手安装模型，再开启开关。模型只在主动安装时下载，识别在本地完成，识别出的文字交给所选翻译服务。

目前主要支持静态网页图片；复杂纹理背景、倾斜文字及密集小字的覆盖效果仍可能不理想。PDF 扫描件暂未接入图片 OCR。此发布提供 GitHub 安装包，扩展商店更新另行提交。
