# WuPage v1.20.0

## 新功能

- 翻译服务新增 DeepL 和 Index-Translate。DeepL 支持 Free、Pro 和自定义接口，Index-Translate 可连接官方桥接或自行部署的服务。
- 字幕外观新增西文版式。原文和译文左对齐，原文随播放逐词显示，译文按完整语句翻译。中文版式继续居中分屏显示。[#74](https://github.com/mr-wuliu/wupage/issues/74)
- 自定义配色支持单独调节每种颜色的透明度，也可在方案选择器下方直接重命名。[#75](https://github.com/mr-wuliu/wupage/pull/75)

## 改进与修复

- 翻译请求的全局默认并发数从 3 提升至 5，仍可在性能设置中调整。[#75](https://github.com/mr-wuliu/wupage/pull/75)
- 改善学术 PDF 翻译对公式、引用编号和跨栏参考文献的保留。
- 改善 Chrome 和 Edge 下载 Bergamot 本地翻译模型的兼容性。
- 修复扩展重新加载后，旧页面脚本访问失效的扩展接口时反复报错的问题。视频播放器可恢复原生字幕。

## 更新说明

更新后请刷新已打开的网页。解压安装需要手动替换安装包并重新加载扩展。Edge 和 Firefox 商店版通过各自商店更新。GitHub Release 中的 Firefox ZIP 未经 Mozilla 签名，仅供临时测试。
