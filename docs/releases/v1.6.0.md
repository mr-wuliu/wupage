# WuPage v1.6.0

## 新功能

- **翻译排除规则**：可按网站、网址路径和 CSS 选择器指定保留原文的区域，支持动态加载内容。初始仅预置 X（x.com）侧边导航栏规则，可编辑、停用或删除。规则采用列表展示，点击下拉箭头展开详情。
- **暂停画面翻译**：安装 OCR 模型并开启图片翻译后，可暂停视频，识别画面中的课件、菜单等文字并显示译文，无需视频提供字幕。文字识别在本地完成，仅将识别出的文字交给翻译服务。
- **中文拼音查词**：划选中文单字或不超过 8 个汉字的词语，可查看有道汉语词典提供的带声调拼音和释义，多音字释义标注对应读音。
- **本地使用统计**：新增翻译页面数、请求次数、成功率、响应时间、缓存命中和模型用量等统计，支持最近 7／30／90 天查看。默认关闭，数据仅保存在当前浏览器；Token 用量只统计接口实际返回的数据。

## 优化

- 优化长页面和动态网页的增量扫描、段落处理与缓存读写，减少翻译过程中的页面卡顿和重复计算。
- 改善开放式网页组件中的正文翻译，以及页面重建、样式变化后的译文显示与原文恢复。
- 连续字幕片段按语句合并翻译，改善字幕阅读连贯性，并修正 Google 翻译服务的上下文对齐。
- 在支持的播放器中，将字幕翻译入口接入原生操作栏，并随原生控件显示和隐藏；改善 YouTube 移动网页的字幕读取与触摸操作。

## 修复

- 修复偶发的重复点击同一段落后，译文不断追加的问题。
- 修复 Steam 社区与创意工坊中部分简介、新闻、讨论和创意工坊条目标题漏译的问题。
- 修复暂停画面文字识别失败提示长期停留的问题，提示会自动消失；改善设置保存反馈，成功提示会自动收起。
- 修复 X 视频控件受翻译影响的问题，并在全屏播放时隐藏页面悬浮工具。
- 修复 Anthropic 兼容服务的默认请求参数与浏览器调用兼容问题。
- 改善请求取消、超时、限流及响应中断后的处理，避免旧任务占用翻译队列，并保留失败信息供重试。
- 修复连续打开不同 PDF 时，旧文档的加载结果可能干扰新文档的问题。

更新后，请重新加载扩展，并刷新已打开的网页。
