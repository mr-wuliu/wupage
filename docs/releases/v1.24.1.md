# WuPage v1.24.1

## Chrome 商店安装

WuPage 已在 [Chrome 网上应用店](https://chromewebstore.google.com/detail/wupage-translator/oimcejdmobjcmiklbidamgpfmgkdaiej) 上线。商店版由 Chrome 自动更新，可在详情页查看当前版本。从解压安装或独立 CRX 切换前，请先导出设置，安装商店版后再导入。

## 修复

- 修复悬浮面板配色被网页或 Dark Reader 覆盖，以及网页重写样式后悬浮球透明度恢复为 100% 的问题。 [#112](https://github.com/mr-wuliu/wupage/issues/112) · [#113](https://github.com/mr-wuliu/wupage/issues/113)
- 改善隐藏悬浮球、语言和翻译模式下拉菜单的文字与背景对比度。 [#111](https://github.com/mr-wuliu/wupage/issues/111)
- 整页翻译会跳过划词词典及其他扩展浮层中的文字。

## 更新说明

更新后请刷新已打开的网页。解压安装需要手动替换安装包并重新加载扩展。GitHub Release 中的 Firefox ZIP 供临时测试使用。
