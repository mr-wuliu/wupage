# WuPage v1.8.0

## 改进

- PDF 翻译支持同页跨栏和相邻页的段落续接。连续段落一起翻译，再按原有区域显示，保留公式、引用及文字格式。
- 跨页段落共用翻译任务，翻页、重试和导出复用已完成的译文，并保留手动校对。为支持上下文的翻译服务补充相邻页原文，改善跨页衔接。
- 改善使用连续换行排版的旧式网页翻译，按真实段落采集正文，支持滚动补译、动态更新及恢复原文。

## 修复

- 修复安装完整 PDF 导出字体后，部分英文字母消失或显示为三角乱码的问题。
- 修复居中附录标题之后的正文被误判为参考文献，导致部分栏位漏译的问题。
- 修复 arXiv 不带 `.pdf` 后缀的 PDF 地址无法识别、点击翻译时出现页面连接错误的问题。

## 更新说明

更新后，请重新加载扩展，并刷新已打开的网页和 PDF 翻译页。Edge 和 Firefox 商店版通过各自商店更新；GitHub Release 中的 Firefox ZIP 未经 Mozilla 签名，仅供临时测试。
