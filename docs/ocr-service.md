# 自定义 OCR 接口协议

在「设置 → 常规 → 文字识别」选择「自定义 OCR 服务」，填写完整接口地址、模型名称和可选密钥，点击「测试识别」检查返回的文字与位置，开启图片翻译并保存。模型运行在服务端，扩展不下载其权重或执行代码。

## 请求

扩展对配置的完整地址发送一次 `POST`，不自动追加路径。示例地址为 `http://127.0.0.1:8000/v1/ocr`，也支持局域网 HTTP 或远程 HTTPS 地址。远程服务应使用 HTTPS。接口不能依赖网页 Cookie 登录，也不应重定向到其他地址。

请求头为 `Content-Type: application/json`；填写密钥时额外携带 `Authorization: Bearer <API key>`。不附加原网页地址、原站点 Cookie 或翻译服务凭据。服务端可以按其环境验证扩展请求来源，认证须使用单独的 OCR 密钥。

```json
{
  "schemaVersion": 1,
  "model": "my-ocr",
  "image": {
    "dataUrl": "data:image/png;base64,...",
    "width": 640,
    "height": 160
  }
}
```

`dataUrl` 为 PNG、JPEG 或 WebP 的 Base64 数据 URL。尺寸为送入识别服务的图片像素尺寸，不是网页上的显示尺寸。图片至多 12 MiB、单边至多 4096 像素，总计至多 1600 万像素。扩展可能已将网页原图或视频画面缩放；服务端还应核验解码后的实际尺寸并限制内存使用。

## 成功响应

返回 HTTP 200 和 JSON，`lines` 按阅读顺序排列。没有文字时返回空数组。

```json
{
  "schemaVersion": 1,
  "coordinateSpace": "pixel",
  "width": 640,
  "height": 160,
  "lines": [
    {
      "text": "Hello OCR 123",
      "score": 0.98,
      "poly": [[32, 50], [360, 50], [360, 100], [32, 100]]
    }
  ]
}
```

| 字段 | 要求 |
| --- | --- |
| `schemaVersion` | 数字 `1` |
| `coordinateSpace` | 固定字符串 `pixel` |
| `width`、`height` | 与请求图片尺寸完全一致 |
| `lines` | 最多 2000 个文字区域，按阅读顺序排列 |
| `text` | 非空原文，单区域至多 4000 个 JavaScript 字符，总计至多 100000 个；不要提前翻译或返回 Markdown |
| `score` | 可选，有限数字，范围 0–1；提供时低于 0.6 的区域不参与覆盖，省略时保留区域，不伪造置信度 |
| `poly` | 恰好四个 `[x, y]` 点，沿框的边界顺序排列，通常从左上角起顺时针；坐标须有限、在图片范围内，区域面积至少 1 平方像素 |

坐标以请求图片的左上角为 `(0, 0)`。服务内部缩放、补边、切片或旋转后，必须将输出映射回请求图片。纯文本输出、归一化坐标、模型输入尺寸坐标均不能直接使用。框应尽量贴合文字行，避免将整张图片作为一个框；扩展根据文字区域覆盖原文并绘制译文。

完整响应体不得超过 4 MiB。字段、尺寸、坐标或置信度不符合协议时，整次识别失败，不进行部分覆盖。服务错误返回非 2xx 状态，扩展仅显示状态及通用错误，不显示服务端错误正文。请求上限为 90 秒，图片翻译同时最多运行两张图片；扩展不自动重试识别或切换至其他 OCR。

## 测试与缓存

「测试识别」发送扩展生成的 640 × 160 图片，其中有 `Hello OCR 123`。它使用当前表单内容，无需先保存，也不调用翻译服务。预览展示服务返回的文字框和原文；连接成功但无文字会单独提示。取消测试或修改字段会停止等待并取消请求，服务端已接收到的任务仍可能继续处理。

缓存按 OCR 地址、模型名称、密钥、用户填写的模型缓存版本和翻译配置隔离，密钥仅参与本机哈希计算，不作为明文缓存键。服务端更换同名模型的权重后，将「模型缓存版本」从 `1` 改为 `2` 等新值，或清除翻译缓存。扩展不探测服务器权重变化。

切换 OCR 配置或关闭图片翻译时，进行中的自定义 OCR 请求会取消；已经完成但配置过期的结果不会用于后续翻译或写入缓存。自定义服务失败时不自动改用内置 OCR。

## 对接已有模型

在模型服务前增加一个协议适配层：校验认证和请求，解码图片，按 `model` 选择模型执行识别，将模型返回的框转换为请求图片上的四点坐标，再按上述 JSON 返回。模型库、GPU、字典和前后处理由服务端维护。

自定义服务收到的是图片像素；识别出的文字继续交给扩展所选的翻译服务。仅连接可信任的服务，按服务提供方的策略管理处理记录与图片留存。扫描 PDF 暂未接入此接口。
