# 翻译系统审视

本次检查覆盖网页文本提取、段落翻译、后台服务商适配、批次调度、缓存、保护占位符，以及 PDF 和 OCR 图片翻译接入同一后台链路的方式。判断特化代码是否应保留时，主要检查其是否依据稳定的结构或协议、是否猜测原文含义，以及是否有正反向回归用例。

## 已调整的行为

| 发现 | 调整与理由 |
| --- | --- |
| 网页渲染器把重复的代码占位符按出现顺序分配回原代码；PDF 则拒绝错误 ID | 网页整页与段落请求都启用保护校验，复用 PDF 的恢复链路。只规范括号、空格、大小写等无歧义变化；允许正确 ID 调序，禁止凭位置猜测。渲染器收到无效结果时保留原文。 |
| 单个输入对应多个模型输出字符串时直接拼接 | 输出条数必须对应输入。异常结果走有限重试，避免把多余条目或解释拼进用户看到的译文。保留单条纯文本和 JSON 字符串兼容，但拒绝截断 JSON 与未闭合代码围栏。 |
| 是否恢复取决于错误消息是否以 `LLM response ` 开头 | 使用专门的响应异常类型。格式问题可拆批恢复；HTTP、网络和 HTML 配置错误直接返回，避免无效请求倍增。 |
| 为邮件添加的 `div` 分组仅识别 `[role=main]`，且能吞并标题 | 共享正文区域和叶级段落规则，同时覆盖语义化 `main/article`。优先尊重标题、段落和控件结构，保留作者换行的布局处理。 |
| 短词、标点等不能单独翻译的片段会被收入整段请求，却未全部纳入替换追踪 | 整段渲染追踪完整原文片段。替换模式不会留下短词或标点，也不会在重新扫描时为这些残余片段再次请求翻译。 |
| `.Label/.State/.Counter` 和 breadcrumb 类名子串被全局排除 | 删除这些过宽条件，防止普通文章因同名样式类而漏译；保留明确的导航、面包屑节点及平台组件选择器。 |
| 上下文只排除整块隐藏内容，没有过滤段落内部的隐藏节点与草稿 | 逐文本读取来源，过滤扩展译文、隐藏子树、脚本、样式和编辑区；正文提取同时覆盖空值与 `plaintext-only` 编辑区。 |
| X 与 YouTube 各自拆分换行，其中 X 扫描会触碰已生成译文 | 共用按原始换行拆分的实现，跳过扩展内容；帖子分段也排除已有译文，避免译文混入原文。 |
| 为规避内容脚本模块导入而复制性能参数与服务商类型判断 | 将内容脚本独立打包为 IIFE，保留其他扩展页面的模块构建。前后台复用性能配置与服务商分类；不再依赖复制逻辑规避打包限制。 |
| 缓存读写失败导致有效译文被整个丢弃 | 缓存作为可选加速层，读写失败仍返回有效译文。缓存命名空间升级，避免复用旧响应规则留下的结果。 |

## 保留的兼容处理

- **YouTube 简介逐行排版**：简介包含保留换行的文本、链接与视频卡片，逐行与链接边界具有结构依据；保留新旧渲染器适配。
- **X 帖子的单换行与空行分段**：保留作者排版，不能将所有换行统一折叠成空格。
- **Reddit 命名 slot**：元数据和正文分属不同插槽，译文需要保留正文的插槽与插入位置。
- **GitHub 代码注释**：普通行、虚拟定位行和表格行的固定高度要求不同；保留独立样式，避免行号错位。
- **Ollama Origin 兼容**：这是服务端请求协议差异，已有开关、限定到端点的规则和生命周期测试。
- **PDF 公式保护与字形裁剪**：依据字体、坐标、上下标和相邻正文作判断，不依赖具体论文的译文；保留公式原图和局部修复。
- **OCR 参考文本补标点**：仅在全部字母、数字与识别结果一致时使用替代文本恢复标点；保留不同名称、普通图片描述和远距离分栏的反例约束。

## 验证与边界

- 单元与 DOM 回归覆盖四类 LLM 服务商的异常输出、错误分类、缓存故障、完整源文本替换、代码 ID 调序、正文分组、草稿和隐藏内容过滤。
- `npm run test:page` 使用真实构建扩展与本地模拟服务，检查整页和段落入口、模式切换、窄窗口、恢复原文及迟到响应。
- 现有 PDF、OCR、图片覆盖、YouTube 与 GitHub 回归继续验证保留的适配。浏览器测试入口与环境变量见 [开发指南](development.md)。

这些测试可以验证请求、结构和显示行为，不能保证外部模型的语义翻译质量，也不能保证第三方网站未来不改版。新增适配应同时提供普通结构的反例，避免把单站点问题扩大成全局排除规则。

## 2026-11-02：用户环境与故障恢复复查

本轮重点检查正文采集与恢复、动态文档生命周期、请求队列、缓存依赖、选区边界、前台初始化、PDF 打开过程，以及 HTTP 页面中共用工具的可用性。下列问题已经修复，并加入对应回归。

| 问题 | 修复与兜底 |
| --- | --- |
| 请求在收到响应头后清除超时和取消监听，正文卡住会持续占用队列 | 超时与用户取消持续覆盖正文读取；读取正文限制为 4 MiB，拒绝异常大响应，避免失控分配内存。LLM 重试共用 90 秒预算，等待可取消；过长的 Retry-After 交给暂停与手动恢复。 |
| 普通服务的 401、403、429 与额度错误没有进入统一暂停机制 | 保留可识别错误类型，页面与嵌入文档复用现有暂停机制；恢复原文仍可用，明确重试后重建任务。不自动切换服务或发送给其他服务。 |
| 一个并行分组失败后，其他工作线程仍会继续派发剩余分组 | 失败后停止继续派发；已经开始的并行任务保留原有生命周期。全局并发器使用独立身份，避免导入的服务 ID 与其重名造成死锁。 |
| code / 紧凑控件的采集例外能绕过编辑区排除 | 在所有特化规则之前检查不可采集区域；正文、上下文与自动语言样本共享保护。跨越编辑区的划词选区也拒绝发送。 |
| translate=no、notranslate 和 MathML 没有统一边界 | 尊重有效的继承与重新启用标记；行内禁止翻译内容与 MathML 使用受保护标记，本地恢复原节点内容；独立 MathML 和 SVG 不作普通正文处理。 |
| 活动译文的代码、公式或保留文字变动后，旧保护节点仍可能显示 | 追踪保护来源的文字和结构，排除扩展自己的隐藏类；来源更新时撤销旧结果并恢复当前原文，再交给增量采集。 |
| 网站整体替换 document.body 后，监听器仍停留在旧 Body | 观察文档根元素，继续接入新正文；停止翻译时恢复当前文档。 |
| 会话存储读取失败会保留一个已拒绝的 Promise，永久阻断该标签页 | 会话持久化作为可选层；必需设置读取失败后释放失败记录，下次操作可恢复。前台注册失败也清除待启动状态。 |
| 图片缓存或 OCR 安装状态检查失败会阻断正常功能 | 图片缓存读写失败仍返回有效结果；OCR 缓存不可用时仍能读取设置，不据此永久关闭已有开关。 |
| 单个可选前台功能初始化抛错，后续功能全部停止初始化 | 各功能独立初始化并记录错误，保留其他入口和设置监听。 |
| 普通 HTTP 页面不暴露 randomUUID，站点规则和视频会话无法创建 | 使用密码学随机数的 UUID 后备实现，兼容未提供 randomUUID 的文档。 |
| 旧 PDF 下载或解析晚返回，会覆盖新打开的文件 | 每次打开单独持有取消状态，隔离过期下载、解析、文件权限结果和清理；正文下载持续受期限与取消约束。文件名包含不完整百分号编码时仍可打开。 |
| 译文调试记录没有限制单条结果长度 | 与原文记录采用相同截断，限制长响应的内存驻留。 |

Fetch 在响应头到达后即可兑现，正文仍是独立异步读取，因此取消必须持续到正文消费结束；参见 [MDN Fetch 文档](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch)。`translate` 的继承、`no` 与 `yes` 行为依据 [HTML 标准](https://html.spec.whatwg.org/multipage/dom.html#the-translate-attribute)。

### 验证与剩余边界

- 首次复查验证：类型检查、122 个测试文件中的 1,537 个用例、39 项发布脚本模拟测试、Chromium / Firefox 构建全部通过。新增 36 个单元与 DOM 回归用例；浏览器回归使用 Chrome 156、Edge 156 和 Firefox 159。
- 单元和 DOM 回归同时检查异常与恢复；另保留既有 PDF、OCR、服务商、视频与设置测试。
- `test:resilience` 在真实 Chrome、Edge、Firefox 中使用本地原创网页和模拟服务验证；宽窄窗口与三种显示模式均检查恢复原文和控件操作，并验证真实网络正文取消。现有网页、嵌入文档和卡片回归继续验证原有行为。
- 样本测试不等于所有真实网站验收。开放式 Shadow DOM 正文已在后续修复中纳入采集；封闭组件、Canvas 绘制内容、浏览器禁止注入的页面，以及站点未来更换结构仍有边界。
- 本轮不是第三方运行库、所有站点、所有设备或商业运营的完整审计。发布脚本通过现有模拟测试；没有调用真实商店、真实付费服务或改变发布状态。

### 继续修复与完整回归

| 后续发现 | 修复 |
| --- | --- |
| 普通开放式组件的正文未进入统一采集与恢复 | 接入开放式 Shadow Root 与嵌套组件，监听组件内增量更新；样式在各树独立安装，恢复原文跨宿主执行，分组不跨越组件树。段落点击与快捷键定位到组件内原始目标。 |
| 组件宿主的编辑区、禁止翻译与隐藏状态容易被内部采集绕过 | 采集与上下文检查沿宿主继承边界，可见性检查包含宿主的隐藏与裁剪；动态禁止翻译同时撤回正文和已翻译的输入框提示。 |
| 网站移除或清空扩展样式，或用强制样式隐藏译文 | 延迟恢复文档与组件内样式，防止同步反复重建；生成译文不可见时撤回替换并保留原文，独立片段继续处理。 |
| 虚拟列表暂时移出页面的节点在停止翻译后仍保留空白原文或加载标记 | 全局恢复同时处理已断开连接的来源、保护节点、提示属性和输出，包括暂存在 DocumentFragment / template 中的节点；这些节点被网站再次插入后仍保持原文，并可重新翻译。 |
| 旧版 Chromium 缺少 AbortSignal.any，取消链路直接报错 | 使用原生能力优先的兼容实现，保留原始取消原因并清理监听；同一文档的重复批次共享组合信号，避免累积监听。 |
| 断网、服务端错误、无效 JSON 没有统一暂停，继续浪费后续段落请求 | 网络中断、服务不可用、错误端点和异常协议进入可恢复的暂停机制；丢弃的响应取消正文读取，仍由用户明确重试。 |
| OCR 已开启时，缓存检查故障阻止保存语言等无关设置 | 仅从关闭切换到开启时要求通过安装检查；已开启状态下，缓存异常不阻断其他设置保存。 |
| 图片控件只观察旧 Body，且没有完整排除编辑区与禁止翻译区域 | 观察文档根节点，恢复被网站移除的控件；统一过滤编辑区、宿主与禁止翻译边界，撤回已失效覆盖层，并释放被拒绝图片响应的网络正文。 |
| 可选后台集成初始化可能阻止主消息入口注册 | 先注册主入口，再独立初始化嵌入文档和视频集成，异常分别记录。 |
| 运行与开发依赖包含公开安全公告 | PDF.js 升至 6.2.108；Vite 升至 7.3.7、Vitest 升至 4.1.12，并更新范围内受影响的间接依赖。同步锁文件，按新测试工具的函数与构造器约定修正测试替身。 |
